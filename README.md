🏛️ Thai Official Document Agent Workspace (Offline-First)
ระบบผู้ช่วย AI ร่างหนังสือราชการและบันทึกข้อความอัจฉริยะ ทำงานแบบ Offline 100% รักษาตราครุฑและรูปแบบ DOCX มาตรฐานงานสารบรรณ

📌 ที่มาและปัญหาที่พบ (The Problem)
การร่างหนังสือราชการไทยด้วย AI ทั่วไป (เช่น ChatGPT หรือ Claude โดยตรง) มักเจอปัญหาหลัก 3 ข้อ:

รูปแบบเพี้ยน 100%: AI ที่สร้างไฟล์ Word ขึ้นมาใหม่จากศูนย์ มักจะทำตำแหน่งตราครุฑ ระยะขอบหน้ากระดาษ ขนาดฟอนต์ TH Sarabun New และระยะห่างบรรทัดผิดระเบียบสำนักนายกรัฐมนตรี
ความปลอดภัยของข้อมูลราชการ (Data Privacy): เอกสารราชการมักมีข้อมูลส่วนบุคคลหรือชั้นความลับ การส่งเนื้อหาขึ้น Cloud API เสี่ยงต่อการรั่วไหล
สำนวนไม่ตรงกับองค์กร: แต่ละหน่วยงานมีแบบแผนการขึ้นต้น การลงท้าย และการระบุเส้นทางเสนอหนังสือเฉพาะตัว
โปรเจกต์นี้จึงถูกออกแบบมาเพื่อแก้ปัญหาเหล่านี้อย่างสมบูรณ์แบบ!

✨ จุดเด่นของระบบ (Key Features)
🔒 Offline-First 100%: ทำงานบนเครื่องของคุณทั้งหมด ไม่มีการส่งข้อมูลออกนอกเครื่อง และไม่ต้องเสียค่าใช้จ่าย Paid API ใดๆ
🦅 Preserve Real DOCX Templates: ใช้วิธีคัดลอกไฟล์ DOCX แม่แบบของจริงที่มีตราครุฑและการจัดหน้าถูกต้อง แล้วแทนที่เฉพาะช่อง {{...}} ทำให้ผลลัพธ์คงรูปแบบเดิม 100%
🧠 Self-Learning Style: มีระบบวิเคราะห์และเรียนรู้สำนวน คำขึ้นต้น คำลงท้าย และทำเนียบผู้ลงนามจากตัวอย่างเอกสารจริงที่ผ่านการอนุมัติแล้ว
✅ Automated 6-Dimension Verifier: สคริปต์ตรวจความสมบูรณ์ของเอกสารก่อนส่งงานจริง (ตรวจตราครุฑ, ตรวจ Placeholder ตกค้าง, ตรวจส่วนหัว/ท้าย, ตรวจ Stylesheet, และตรวจเตือนตัวเลขที่ไม่ตรงกับต้นเรื่อง)
🖥️ Interactive Local Dashboard: หน้าเว็บแดชบอร์ดในเครื่อง (เปิดด้วยคลิกเดียว) มีระบบฟอร์มช่วยร่างเอกสาร ค้นหาตัวอย่างงานเก่า และสั่งเปิดไฟล์ใน Microsoft Word ได้ทันที
🤝 Multi-Agent Protocol: รองรับการทำงานร่วมกันระหว่างมนุษย์และ AI หลายตัวผ่านระบบ Lock และสมุดส่งเวร (Handoff Log)
🚀 วิธีนำ Prompt ไปสร้างระบบบนเครื่องของคุณ (Quick Setup)
คุณสามารถสร้างระบบนี้บนเครื่องของคุณได้ง่ายๆ ภายใน 3 นาที โดยใช้ AI Coding Assistant ตัวโปรดของคุณ (เช่น Claude Code, Cursor, Antigravity, Codex, Windsurf, ChatGPT ฯลฯ):

ขั้นตอนที่ 1: เตรียมโฟลเดอร์ว่าง
สร้างโฟลเดอร์ใหม่บนคอมพิวเตอร์ของคุณ เช่น Official-Doc-Agent
เปิดโฟลเดอร์นั้นในโปรแกรม AI หรือ Terminal ของคุณ
ขั้นตอนที่ 2: ใช้ Master Prompt
คัดลอกเนื้อหาทั้งหมดจากไฟล์ 
"PROMPT_TEMPLATE.md"
วาง Prompt ลงในหน้าแชทของ AI Coding Assistant แล้วกดส่ง
AI จะทำการสร้างโฟลเดอร์ สคริปต์ Python ระบบแดชบอร์ด และเทมเพลตเริ่มต้นให้โดยอัตโนมัติ
📖 วิธีการใช้งานระบบในชีวิตประจำวัน (Daily Workflow)
เมื่อระบบถูกสร้างเรียบร้อยแล้ว คุณสามารถใช้งานได้ 2 วิธีตามความสะดวก:

🌟 วิธีที่ 1: ใช้งานผ่านหน้าจอ Dashboard (สำหรับผู้ใช้งานทั่วไป - แนะนำ)
ใส่ไฟล์ตัวอย่างและเทมเพลต:
วางไฟล์แม่แบบ DOCX ในโฟลเดอร์ 01_templates/
วางไฟล์งานหรือคำสั่งที่ต้องทำในโฟลเดอร์ 02_current_work/
วางตัวอย่างงานเก่าที่ผู้บริหารเคยอนุมัติแล้วในโฟลเดอร์ 03_approved_examples/
เปิดหน้าแดชบอร์ด:
บน Windows ดับเบิลคลิกไฟล์ เปิดแดชบอร์ด.cmd
หรือรันคำสั่ง python tools/dashboard_server.py --open
เบราว์เซอร์จะเปิดหน้าเว็บ http://127.0.0.1:8765/ ขึ้นมาอัตโนมัติ
ร่างเอกสารผ่านฟอร์ม:
ไปที่แท็บ "✍️ ผู้ช่วยร่างเอกสารแบบโต้ตอบ"
เลือกแม่แบบงานด่วน (เช่น ขอข้อมูลสถิติ, ขออนุมัติ, เชิญประชุม, ขอใช้ห้อง, ส่งรายงาน)
ปรับแก้ข้อความ หรือกดปุ่ม "🔢 แปลงเลขอารบิกเป็นเลขไทย"
กดปุ่ม "🚀 สร้างเอกสาร DOCX ทันที"
เปิดตรวจและสั่งพิมพ์:
กดปุ่ม "📂 เปิดเอกสารใน Word" เพื่อเปิดไฟล์ผลลัพธ์ขึ้นมาตรวจทานและสั่งพิมพ์ได้ทันที
🤖 วิธีที่ 2: สั่งงานผ่าน AI Agent (สำหรับงานซับซ้อน)
นำไฟล์งานต้นเรื่อง (เช่น บันทึกข้อความหรือ PDF สรุปประชุม) ใส่ไว้ใน 02_current_work/
เปิดแชทกับ AI Agent แล้วสั่งงานด้วยภาษาธรรมชาติ เช่น:
"ช่วยร่างบันทึกข้อความขอความอนุเคราะห์ข้อมูลจากกองแผนงาน โดยอ้างอิงข้อมูลใน 02_current_work และใช้สำนวนตาม 03_approved_examples ให้หน่อย"

AI Agent จะดำเนินการตามขั้นตอนใน AGENTS.md:
สแกนข้อมูลและอัปเดตสไตล์ (python tools/update_knowledge.py)
สร้าง Job JSON และสร้างเอกสารจาก Template (python tools/generate_from_template.py)
ตรวจสอบความถูกต้องของโครงสร้างและตัวเลข (python tools/verify_output.py)
ส่งมอบไฟล์ DOCX ที่สมบูรณ์ในโฟลเดอร์ 04_generated/

📜 กฎเหล็กมาตรฐานงานสารบรรณที่ระบบยึดถือ (Core Guidelines)
ไม่สร้าง Layout เองจากศูนย์: คัดลอก Template จริงและแทนที่เฉพาะ Placeholder เพื่อรักษาตำแหน่งตราครุฑและระยะขอบกระดาษ
ตัวเลขไทย: ใช้เลขไทย (๑ ๒ ๓...) ในเนื้อหาภาษาไทยทั้งหมด
ภาคเหตุ (ย่อหน้า ๑): อ้างอิงที่มาให้ครบถ้วน และต้องลงท้ายด้วยคำว่า นั้น เสมอ
ภาคความประสงค์ (ย่อหน้า ๒): ขึ้นต้นด้วยคำเชื่อมทางการ เช่น ในการนี้ [ชื่อหน่วยงาน] จึงใคร่ขอความอนุเคราะห์... พร้อมระบุข้อมูลติดต่อท้ายย่อหน้านี้
ภาคสรุป (ย่อหน้า ๓): ขึ้นบรรทัดใหม่แยกเดี่ยวตามแบบทางการ เช่น จึงเรียนมาเพื่อโปรดพิจารณาให้ความอนุเคราะห์ จักขอบคุณยิ่ง
🔒 นโยบายความปลอดภัยและความเป็นส่วนตัว (Privacy Policy)
100% Offline by Default: ไม่มีฟังก์ชันใดในระบบที่ส่งข้อมูลออกไปยังเซิร์ฟเวอร์ภายนอก
No Paid API Required: สคริปต์ทั้งหมดทำงานด้วย Python และ Standard Library / Open-source Libraries ท้องถิ่น
Confidential Safe: ปลอดภัยสำหรับการใช้งานกับเอกสารภายในและเอกสารชั้นความลับของหน่วยงาน
